# 🗓️ Расписание лицея — веб-приложение (Frontend + Backend)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/allexme8-create/Raspisanie)

Веб-приложение для публикации расписания уроков лицея.

- **Администратор** через админ-панель загружает два файла расписания
  (`Учителя` — в ячейках фамилии учителей с кабинетами, `Предметы` — названия предметов).
  Файлы можно загрузить с устройства или по публичной ссылке **Яндекс.Диска**.
- **Ученики, родители и учителя** открывают сайт и сразу видят готовое расписание:
  по классам, по учителям, свободные кабинеты и «⭐ Избранное».
- Интерфейс адаптирован под **мобильные устройства** (нижняя навигация, карточный вид).
- Установка не требуется — всё работает в браузере через сервер.

## Быстрый запуск (локально)

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# задайте пароль администратора (по умолчанию: admin123)
export ADMIN_PASSWORD="мой-секретный-пароль"   # Windows: set ADMIN_PASSWORD=...

python app.py                    # или: uvicorn app:app --host 0.0.0.0 --port 8000
```

Откройте в браузере:

| Страница | Адрес |
|---|---|
| 📅 Клиент (расписание) | http://localhost:8000/ |
| 🛠️ Админ-панель | http://localhost:8000/admin |
| 📄 Документация API | http://localhost:8000/api/docs |

### Docker

```bash
docker build -t raspisanie .
docker run -p 8000:8000 -e ADMIN_PASSWORD="секрет" -v raspisanie_data:/app/backend/data raspisanie
```

Том `raspisanie_data` сохраняет загруженные файлы между перезапусками.

## Работа администратора

1. Откройте `/admin`, введите пароль (`ADMIN_PASSWORD`).
2. Загрузите **оба файла расписания** — тип («Учителя»/«Предметы») определяется
   автоматически по содержимому:
   - 🖱️ перетащите `.xls/.xlsx/.xlsm/.xml/.csv` в зону загрузки, **или**
   - вставьте публичную ссылку **Яндекс.Диска** (`https://disk.yandex.ru/i/…`) —
     сервер сам скачает файл (на сервере нужен выход в интернет).
3. После загрузки расписание сразу становится доступно всем посетителям —
   обновлять ничего не нужно. В карточке наверху видна дата обновления.

Для быстрой проверки в каталоге `samples/` лежат два тестовых файла
`Пример_учителя.xlsx` и `Пример_предметы.xlsx`.

## API (кратко)

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/schedule` | публично | Готовое расписание (сетки обоих файлов) |
| GET | `/api/status` | публично | Готовность данных |
| POST | `/api/admin/login` | — | `{password}` → `{token}` |
| GET | `/api/admin/status` | Bearer | Информация о загруженных файлах |
| POST | `/api/admin/upload` | Bearer | multipart `files` — 1..N файлов |
| POST | `/api/admin/fetch-yandex` | Bearer | `{url}` — скачать с Яндекс.Диска |
| DELETE | `/api/admin/file/{kind}` | Bearer | Удалить файл (`teachers`/`subjects`) |

## Формат файлов расписания

Формат полностью совпадает с исходным HTML-приложением:

- строка заголовка содержит названия классов, начиная с `5а` (`5а 5б 5в … 11б`);
- в первом столбце — дни недели `Пн Вт Ср Чт Пт Сб`, рядом — номер урока;
- ячейка: `Алгебра, Геометрия (12, 14)` — значения через запятую, кабинеты в скобках;
- в файле «Учителя» вместо предмета — фамилия учителя, например `Иванова ИИ (305)`;
- служебные ячейки: `Классный час`, `СФУ`, `Экскурсия` (без кабинета).

## Конфигурация

| Переменная окружения | По умолчанию | Назначение |
|---|---|---|
| `ADMIN_PASSWORD` | `admin123` | Пароль входа в админ-панель |
| `PORT` | `8000` (в Docker — `7860`) | Порт HTTP-сервера |
| `BACKUP_GH_TOKEN` | — | GitHub-токен для автобэкапа расписания |
| `BACKUP_GH_REPO` | — | Репозиторий бэкапа, напр. `allexme8-create/Raspisanie` |
| `BACKUP_GH_BRANCH` | `schedule-data` | Ветка бэкапа (создаётся автоматически) |
| `BACKUP_GH_PATH` | `backup/state.json` | Путь файла состояния в репозитории |

Если заданы `BACKUP_GH_TOKEN` и `BACKUP_GH_REPO`, после каждой загрузки файлов админом
расписание автоматически коммитится в GitHub, а при старте сервера с пустым диском —
восстанавливается оттуда. Это спасает на бесплатных хостингах с эфемерной ФС.

> ⚠️ Перед публикацией в интернете обязательно смените пароль администратора
> и раздавайте сайт по HTTPS (например, через nginx/Caddy).
